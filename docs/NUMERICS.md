# Numerical notes\n\nThe FFT split operator implements Strang splitting,\n\n$$e^{-iH\Delta t}=e^{-iT\Delta t/2}e^{-iV\Delta t}e^{-iT\Delta t/2}+O(\Delta t^3),$$\n\nwhich gives second-order global convergence for a time-independent $T+V$. Each factor is unitary for Hermitian $T$ and $V$, so norm conservation is limited only by floating-point error.\n\nCrank-Nicolson is also unitary for a Hermitian discrete Hamiltonian. RK4 is included as a useful general ODE reference, but it is not exactly unitary and should be convergence-tested.\n
